# أطلس تاريخ الفلسفة (Philosophy Timeline Atlas)

موقع تفاعلي باللغة العربية يعرض تاريخ الفلسفة وأعلام الفكر الإنساني على خريطة تاريخية تفاعلية يتحكم بها شريط زمني ذكي.

An interactive Arabic-language website visualizing the history of philosophy, early wisdom literature, and religious thinkers on a historical world map controlled by a timeline slider.

## الوثائق الأساسية (Core Documentation)

- **[CONTEXT.md](./CONTEXT.md)**: المرجع الأساسي والشامل للمشروع، القرارات التقنية المعتمدة، نموذج البيانات، وقواعد التحقق.
- **[PLAN.md](./PLAN.md)**: خطة العمل والمراحل والمهام التفصيلية ومتابعة الإنجاز.

## التشغيل والتطوير (Development)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل بيئة التطوير
npm run dev

# التحقق من صحة البيانات
npm run validate

# جلب وتحديث بيانات ويكيبيديا وويكي بيانات
npm run fetch-wiki
```
